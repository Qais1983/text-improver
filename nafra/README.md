# النّفرة — سيرة الرِّكيب (Flipbook Web App)

تطبيق ويب لكتاب **«النّفرة: الرِّكيب.. سِيرة التكاتُف والتضافُر والأثر»**، موجَّه
للهاتف أولاً، بتجربة تقليب ورقيّ حقيقية عبر [StPageFlip](https://github.com/Nodlik/StPageFlip).
المحتوى مستخرَج آلياً من مخطوط Word المصدر، ويُعامَل مصدرَ حقيقةٍ لا يُعاد صوغه ولا
يُصحَّح ولا يُختصر.

## المصدر والاستيراد

- المخطوط المصدر: `scripts/source/manuscript.docx` (ودليل التنفيذ `scripts/source/guide.docx`).
- المستورِد `scripts/import_manuscript.py` يقرأ المستند بترتيبه (فقرات + جداول)،
  ويقسّمه وفق علامات `[[PAGE ...]]`، ويحفظ فقط ما بين `[[CONTENT]]` و`[[/CONTENT]]`،
  ويتجاهل كتل `[[DESIGN NOTE ...]]`. المخرجات:
  - `src/content/book-pages.json` — 100 صفحة مرتّبة.
  - `src/content/donors.json` — 313 مساهمة.
- **مدقّقات تُفشِل البناء** إن اختلّ العدد (100 صفحة)، أو تكرّر معرّف صفحة، أو ظهر اسم
  فارغ أو مبلغ غير رقميّ، أو تسرّبت مساهمة مليونية إلى دفتر النفرة أو العكس.

يُشغَّل تلقائياً ضمن `npm run build`، أو يدوياً عبر `npm run import`.

## قواعد المساهمات (مالية/توثيقية)

- 47 مساهمة بلغت مليون جنيه فأكثر، كلٌّ في صفحة مستقلة، مرتّبة تنازلياً بالمبلغ،
  وعند التعادل حسب ترتيب السجل الأصلي.
- 266 مساهمة دون المليون في «دفتر النفرة»، بترتيب السجل الأصلي، مع **الاحتفاظ بأرقام
  السجل الأصلية وفجواتها** (لا إعادة ترقيم، لا دمج، لا حذف).
- الإجمالي: **221,423,000 جنيه سوداني**. منطق الفرز/القسمة في `src/lib/donors.ts`
  ومغطّى باختبارات `src/lib/donors.test.ts`.

## التشغيل

```bash
npm install
npm run dev        # خادم تطوير
npm run build      # استيراد + فحص أنواع + بناء إنتاجي (PWA)
npm run preview    # معاينة نسخة البناء
npm test           # اختبارات vitest
npm run screenshots # لقطات QA على أحجام هواتف حقيقية (Playwright)
```

> اختبار اللقطات يتطلّب خادم `npm run preview` قائماً على المنفذ 4173، وChromium
> (يلتقطه Playwright من `/opt/pw-browsers` في بيئة التطوير).

## البنية التقنية

- **Vite + React + TypeScript**، والتقليب عبر `page-flip` (صفحات HTML حقيقية، ظلال
  وانثناء هندسيّ، لا شرائح ولا تلاشٍ).
- **RTL كامل**: `dir="rtl"`، والأرقام المالية داخل عناصر `direction:ltr; unicode-bidi:isolate`
  كي لا تنقلب الفواصل. الأسماء تُنقل حرفياً بلا تطبيع.
- **صفحة واحدة في الوضع الرأسي**، وصفحتان في الأفقي فقط حين يبقى عرض الصفحة ≥ 320px.
  لا يوجد وضع تمرير (Scroll Mode) إطلاقاً.
- **خطوط مضمّنة** عبر `@fontsource` (Noto Kufi Arabic للعناوين، Amiri للمتن،
  Noto Sans Arabic للواجهة) وتُخزَّن في الـ Service Worker.
- **PWA**: `vite-plugin-pwa`، قابل للتثبيت، يعمل Offline بعد أول فتح، ويحفظ آخر صفحة.
- **الوصول**: `aria-label` عربيّ لكل صفحة وزرّ، إعلان `aria-live` عند التقليب، حجم لمس
  ≥ 44px، واحترام `prefers-reduced-motion`.

## قوالب الصفحات

`src/pages/PageView.tsx` — قالب لكل نوع: الغلاف، العنوان، الإهداء، السرد، الجسر،
الأثر في أرقام، المساهم المليونيّ، افتتاح دفتر النفرة، قائمة الدفتر، الخاتمة، بيان
النسخة، الغلاف الخلفي.

## النشر

نسخة ثابتة قابلة للنشر على أي استضافة HTTPS (Vercel/Netlify/Cloudflare Pages).
لتغيير مسار القاعدة: `BASE_PATH=/sub/ npm run build`.
